# Font sources

The game's three typefaces, fetched unchanged from the Google Fonts repository at
commit `5bd87dfc525c8a0d1d8529d3684716e00c3fc59a` by `tools/fetch_fonts.py`, which pins
every file by URL and SHA-256. All three are under the SIL Open Font License 1.1,
which allows bundling and redistribution; each licence is kept beside its font. Only
the file names were changed (the variable-font axis tags were dropped from them).

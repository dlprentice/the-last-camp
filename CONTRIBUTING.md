# Contributing

Small, focused fixes and reproducible issue reports are welcome. See
[development](docs/development.md) for dependencies and local checks, and
[architecture](docs/architecture.md) for the source map.

For a bug report, include the Godot version, operating system, GPU/driver,
quality preset, command or location, and a relevant log or screenshot. State
whether it occurs in gameplay or offline Movie Maker output.

Keep changes deterministic and preserve scene composition, walking routes,
prop support and complete asset credits. Visual changes need before/after
captures; cinematic changes need a moving review. Passing unit tests does
not demonstrate visual quality or realtime performance.

Original contributions use the project's [MIT license](LICENSE). External
code or assets must have redistribution terms compatible with inclusion in
a public source repository and must be credited in the relevant source table
or [third-party notices](THIRD_PARTY_NOTICES.md). Do not include credentials,
download caches, engine caches, private logs, generated builds or movies in Git.
